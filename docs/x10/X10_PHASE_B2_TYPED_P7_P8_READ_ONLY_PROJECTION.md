# X10-B2 — Read-only canonical P7/P8 projection boundary

This phase adds `services/x10/typed_projection_v1.py`. The only accepted populated sources are the caller-supplied exact `PaperPortfolioPersistenceSnapshotV1` (P8), and optionally exact `PaperTradePersistenceSnapshotV1` (P7) objects. The function does **not** load, fetch, recover, save or mutate a portfolio; neither a repository method nor a reservation manager is imported. Exact canonical classes are loaded lazily so an entirely unavailable projection works even if those optional legacy dependencies are not installed in a narrow offline fixture.

For a supplied P8 object, the caller provides a detached, expected SHA-256 integrity digest and the time the snapshot became available. P8 created/updated times, underlying snapshot timestamps, event sequence, portfolio identity, PAPER mode, positions and pending count are checked. Every supplied P7 snapshot must match a detached digest, P7 event sequence and position identity, market, remaining quantity and lifecycle state. Absent P7 records result in `P8_ONLY_UNRECONCILED`, not a fabricated recovery certification. The result retains hashes and ordered P7 record identifiers. Caller-supplied time and digests are internal consistency evidence, **not independent authentication** of a position store or proof that no unreported trades exist.

P8 may historically support four equity-index identities. This exact five-market projection does **not** silently omit BANKNIFTY or FINNIFTY positions; a P8 snapshot containing out-of-scope positions raises an error and requires a separately scoped view. NIFTY and SENSEX position counts are projected from P8 typed references. The P8 `PaperCapitalReservationV1` does not carry an unambiguous individual market identity: when P8 has pending holds, their **shared total** is retained and market-specific pending counts stay None, not zero. The shared total is P8-scope, not a five-market capital allocation. All three MCX counts remain None / `MCX_UNVERIFIED` even when caller-provided external research contains quantities.

`X10TypedPortfolioProjectionV1` is always `PARTIAL_DESCRIPTIVE` or `UNAVAILABLE`; all `capital_admission_allowed`, broker/position/risk/execution/certification/live flags remain False, and `deployable_capital` remains None. No P8 reservation is created/modified/released. B2 local unit tests use explicitly identified canonical-interface **test doubles** for P7/P8 shape and guards; this does not certify a real persisted P7/P8 snapshot. A genuine typed-fixture, recover/reconciliation and persisted-source regression in the full repository is a separate B3 gate before any claim of validated runtime integration. Production PAPER counters and positions remain untouched.
