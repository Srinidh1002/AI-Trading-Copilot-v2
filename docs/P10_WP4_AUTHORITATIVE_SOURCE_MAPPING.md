# P10-WP4 — Authoritative Source Mapping

## Certified now

### Option intelligence

Authoritative source:

- `OptionChainIntelligenceResultV1`

Supported display evidence:

- result identity and timestamp
- status
- aggregate directional bias
- aggregate strength
- PCR metrics when present
- support strikes
- resistance strikes
- max-pain strike
- blockers and warnings

Not supported by this contract:

- call/put aggregate open interest
- ATM Greeks
- aggregate Greeks narrative
- discretionary flow narrative

Those fields remain unavailable rather than inferred.

### Runtime operations

Authoritative source:

- `PaperOrchestrationCycleResultV1`
- its ordered `PaperOrchestrationStageResultV1` values

Supported display evidence:

- cycle status
- source timestamps
- total cycle duration
- stage status observations
- stage errors
- cycle warnings/errors

This projection does not run health checks. Stage status is shown as runtime
evidence, not as a newly executed diagnostic.

## Not yet certified

### Market overview

The legacy market snapshot performs acquisition, indicator calculation,
smart-money analysis, option analysis, market-hours calculation, caching, and
performance measurement. It cannot be adapted as a dashboard source.

A typed authoritative runtime data/analysis result is required before market
overview projection is implemented.

### Validation summary

`PaperPortfolioPersistenceSnapshotV1` contains an exact typed
`PaperPortfolioSnapshotV1`, but the nested portfolio snapshot contract must be
audited before selecting completed-trade, win/loss, and realized-P&L fields.

### Decision history

The legacy dashboard history comes from SQLite `decision_log`. No certified
typed history projection source has yet been established. Until one exists,
the replacement view must be unavailable rather than populated from SQLite.

## Projection rules

- exact source contract types only
- no wall clock
- no IDs generated by adapters
- no score or P&L calculation
- no provider, persistence, runtime execution, or Streamlit imports
- missing source evidence remains `None`
- PAPER-only output
